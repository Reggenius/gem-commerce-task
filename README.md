# GEMCOMMERCE TASK

## OVERVIEW

This project is a static web implementation based on a provided Figma design. It focuses on clean web layout structuring and modern UI styling using Tailwind CSS.

## TECHNOLOGIES/TOOLS USED

- HTML5 - Markup
- Tailwind CSS (CDN) - Styling
- Google Font: Inter Tight - Text
- VSCode - Project environment
- Live server (VS Code Extension) - Generate local link
- Chrome and Safari Browsers - View page

## LAYOUT

The page is divided into three sections:

- Top Section
- Middle Section
- Bottom Section
  Each section contains a sub-container with a maximum width of `900px` so as to maintain consistent alignment and readability.

## IMPLEMENTATION DETAILS

- Utilised Tailwind CSS utilitis such as:
  - Flexbox
  - Grid
  - Responsive design (media queries)
- Applied pseudo-elements (`::before`, `::after`) for subtle UI enhancements.
- Designed an adhoc responsive mobile layout to ensure usability across devices, despite the absence of a mobile design in the Figma file.

## PROJECT SETUP

### Clone the Respository

- Open your terminal and navigate to your desired folder
- Run the following command:
  `git clone https://github.com/Reggenius/gem-commerce-task.git`

### Open the Project

You can open the project in any of the following ways:

- Navigate to the project folder and Open the "index.html" file on your web browser
  OR
- Use Live Server VSCode Extension:
  - Open the project folder in your VSCode/drag and drop it
  - Start the VSCode Live server
